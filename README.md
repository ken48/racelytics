# Racelytics

Легкий статический CSV-дашборд для анализа кругов и темпа.

## Использование

Откройте `index.html` напрямую или раздайте папку любым статическим сервером.

Данные можно загрузить так:

- `?src=https://example.com/results.csv`
- поле CSV URL
- локальная загрузка файла или drag-and-drop

Ожидаемые колонки:

```csv
event,place,bib,name,gender,group,course,lap1,lap2,lap3,lap4
2026-06-07,1,104,Maya Chen,F,Женщины 2 круга,Лыжероллерный круг 1.2 км,4:12,8:19,,
2025-06-08,1,117,Luca Rossi,F,Женщины 2 круга,Лыжероллерный круг 1.2 км,4:18,8:31,,
2026-06-07,1,217,Luca Rossi,M,Мужчины 4 круга,Лыжероллерный круг 1.2 км,4:10,8:26,12:39,16:58
```

`event` — это конкретное соревнование, дата или протокол. Например `2026-06-07`, `Контрольная тренировка 2026`, `Кубок клуба 2025`. Место, лидер, отставание и позиция считаются отдельно внутри `event + course + group`. Также поддерживаются алиасы колонок: `race`, `competition`, `date`, `соревнование`, `гонка`, `старт`, `дата`, `протокол`.

`gender` — это атрибут участника. Можно передавать `M/F`, `male/female`, `м/ж`, `мужчины/женщины`.

`group` — это зачет результата: например `Женщины`, `Мужчины`, `U18`, `Open`. Не добавляйте год в название зачета, для этого есть `event`. Также поддерживаются алиасы колонок: `group_id`, `category`, `division`, `class`, `wave`, `зачет`, `группа`, `класс`, `категория`.

`course` — это совместимость трассы/дистанции для графиков: например `Лыжероллерный круг 1.2 км`, `A loop`, `B loop`. Участников с разным `course` нельзя корректно рисовать вместе на одном графике. Если трасса одна и та же в разные годы, оставляйте одинаковый `course`: приложение сможет сравнить темп по трассе, но официальные места останутся разделены по `event`. Также поддерживаются алиасы: `course_id`, `track`, `route`, `distance`, `трасса`, `дистанция`, `маршрут`.

Если `group` не указан, приложение использует `gender` как fallback-зачет для старых CSV.

Если `course` не указан, приложение использует `group` как fallback-трассу для старых CSV.

Если `event` не указан, все строки попадают в одно событие `Соревнование не указано`, чтобы старые CSV продолжали открываться.

UI-правила:

- `Все трассы`: таблица и сводка, графики скрыты.
- Одна `course`, все соревнования и все зачеты: графики времени и кругов доступны как аналитика по трассе.
- Одна `course` и один `group`: доступны лидер, отставание и позиция, рассчитанные отдельно внутри каждого `event`.

Колонки `lap1`, `lap2`, `lap3` и так далее содержат кумулятивные отметки времени на конце круга, а не длительность круга. Например `lap2=8:19` означает, что участник прошел два круга за 8 минут 19 секунд. Приложение само считает длительность каждого круга как разницу между соседними отметками.

Формат времени в CSV: `[HH:]MM:SS`, например `4:12`, `18:56`, `1:02:03`. Секунды без двоеточия не используются.
